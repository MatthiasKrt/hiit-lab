# 🏋️ HIIT Planner

> Web application for planning High-Intensity Interval Training workouts.

## 🚀 Overview

**HIIT Planner** is a web application built with Angular that allows users to design HIIT workouts. It provides a drag-and-drop interface for structuring sessions, including Tabata and custom circuits.

## ✨ Key Features

- **📋 Workout Builder**: Drag and drop interface for creating routines.
- **⏱️ Timers**: Configuration for work, rest, and cool-down periods.
- **📚 Exercise Library**: Collection of exercises with notes and media.
- **🎨 UI**: Interface built with PrimeNG and Tailwind CSS.

## 🛠️ Tech Stack

- **[Angular](https://angular.io/)**: Platform for building web applications.
- **[PrimeNG](https://primeng.org/)**: UI component library for Angular.
- **[Tailwind CSS](https://tailwindcss.com/)**: Utility-first CSS framework.

## 🏁 Getting Started

Follow these steps to set up the development environment:

1.  **Clone the repository**
    ```bash
    git clone <repository-url>
    ```

2.  **Install dependencies**
    ```bash
    npm install
    ```

3.  **Start the development server**
    ```bash
    ng serve
    ```

4.  **Open your browser**
    Navigate to `http://localhost:4200/`. The application will automatically reload if you change any of the source files.
